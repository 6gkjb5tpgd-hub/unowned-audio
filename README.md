#Unowned Audio <br>
This project is an initiative for people to make libre recordings of free texts, since those are usually available in text form over different websites, but not in audio form.<br>
The actual recordings are hosted on archive.org and not on the website's own servers.

Not live yet, out of legal caution (stupid local laws, working on it)

To test locally, download and run `npx wrangler dev` in your terminal.<br>
It will give you a locahost link that you can open to test it.<br>
Signup and Admin stuff shouldn't work because of secrets.<br>
Will work on live version!
